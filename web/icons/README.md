# IG AI production icon contract

The PNGs are the approved production IG AI artwork supplied for this
release. The manifest uses PNG paths for Android/HONOR PWA compatibility and
reserves 192x192, 512x512, maskable 192x192, maskable 512x512, Apple
touch-icon, and favicon slots.

The SVG files are retained as non-selected development/reference artifacts;
the production manifest, browser favicon, Apple touch icon, and app header
all use PNG assets.
