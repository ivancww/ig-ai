# IG AI icon contract

The PNGs and SVGs here are clearly identified development placeholders for
the approved IG AI production artwork. The manifest uses PNG paths for
Android/HONOR PWA compatibility and reserves 192x192, 512x512, maskable
192x192, maskable 512x512, and favicon slots. Replace the PNG files with the
approved source artwork when it is supplied; no app code change is required.

The current PNGs are generated geometric placeholders, not the approved
production logo. `PRODUCTION LOGO INSTALLED` must remain `NO` until that
source asset is actually supplied.
